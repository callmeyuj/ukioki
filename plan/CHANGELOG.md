## V1.2 — 2026/09/22

### 跨模块架构优化（script.js 去重 + CSS 清理）

**script.js（696 → 661 行，-35 行）：**

单一数据源迁移：
- 删除本地 `PRODUCT_DATA`（含未使用的 `avgKcal` 常量），改用 shared/utils.js 共享数据
- `PRODUCT_DATA[petType].flavors` → `getFlavors(petType)`（8 处）
- `pet === 'dog' ? '犬' : '猫'` → `PET_CONFIG[petType].label`

Bug 修复：
- 删除本地 `fmtMoney()`，改用共享 `formatMoney()`（支持千位分隔符：`¥ 1345.12` → `¥ 1,345.12`）

代码去重：
- 新增 `calcPriceSummary()` 提取公共价格计算（原价/折扣/折后/节省），`renderPrice()` 和 `renderSnapshot()` 共用，消除两处重复计算逻辑
- 日期格式化改用共享 `formatDate()`（`init()` + `renderSnapshot()` 两处）

**style.css（946 → 933 行，-13 行）：**

死代码清理：
- 删除未使用的 `.text-price` 工具类
- 删除死代码 `.snapshot-total-right`、`.snapshot-total .text-price`（HTML 结构已不存在）
- 删除重复 `.btn-back-link:hover` 规则（与上方完全相同）

特异性补丁清理：
- 移除 `.snapshot-price-section span.price-actual-label` 的 `span.` 前缀（根因 `.snapshot-field span:first-child` 已加 `:not()` 排除，补丁冗余）

  - 按钮 ID：`btnSaveSnapshot` → `btnContactService`
  - 点击行为：从 html2canvas 截图生成 → 直接显示企微客服二维码（`image/qrcode-service.png`）
  - 新增函数：`showServiceQR()` - 在图片预览弹窗中展示二维码

**技术变更：**
- plan/index.html：HTML 结构调整（快照卡片头部、按钮文案）

## V1.0 — 2026/09/21

### 首个版本：3 屏向导式订阅价格计算器

**index.html / style.css / script.js 初版落地**

**Screen 1 基础配置：**
- 宠物类型（犬默认选中 / 猫置灰 + 敬请期待）
- 订阅总数（≥30 包起订，输入框带「包」单位后缀，复用共享 `.input-suffix`）
- 免邮信息实时显示（⌊总包数 ÷ 30⌋ 次）
- 模拟计算（可折叠，从 calories/ 回程时自动展开 + 预填每日包数 + 默认选中 30 天）
- 展开/收起 icon 底色改为 `--bg-card-selected`（柔和浅米黄，非品牌亮黄）
- 订阅天数：30/90/180 快捷档 + 自定义（小字体确保一行展示）

**Screen 2 口味分配：**
- 工具栏：已分配 X / Y 包 + 平均分配 / 重新分配
- 口味列表：每行显示口味名 + 单价（¥XX/包） + `[− X +]` 控件
- 一键均分：余数优先挂靠单价低的口味
- 价格面板：划线原价 + 折后总价 + 折扣率
- 热量偏差提示（仅回程路径，偏差 > 20% 时显示）

**Screen 3 方案结果：**
- 快照卡片（可见版 + 隐藏版供 html2canvas 渲染）
- 方案明细：宠物、配送日期、订阅总数（加粗）、口味分配
- 价格区：划线原价 + 折后总价（折扣标签淡红色底纹）
- 企微客服二维码（110px，细边框）
- 快照预览弹窗：统一提示「请截图保存后，长按图片添加客服并分享」

**按钮文案优化：**
- Screen 1 → Screen 2：「口味分配 →」
- Screen 2 → Screen 3：「方案结果 →」
- 复用 calories/ 箭头图片（`.btn-next::after`）

**calories/ V3.23 联动（条件隔离，正常入口零感知）：**
- `from=plan` URL 参数检测
- 跳过 Step 0 犬猫选择，犬锁定

- Step 10 商城按钮条件替换为返回按钮
