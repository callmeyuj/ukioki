## V1.0 — 2026/09/21

### 首个版本：3 屏向导式订阅价格计算器

**index.html / style.css / script.js 初版落地**

**Screen 1 基础配置：**
- 宠物类型（犬默认选中 / 猫置灰 + 敬请期待）
- 订阅总数（≥30 包起订，输入框带「包」单位后缀，复用共享 `.input-suffix`）
- 免邮信息实时显示（⌊总包数 ÷ 30⌋ 次）
- 模拟计算（可折叠，从 calories/ 回程时自动展开 + 预填每日包数 + 默认选中 30 天）
- 展开/收起 icon 底色改为 `--bg-card-selected`（柔和浅米黄，非品牌亮黄）
- 订阅天数：30/90/180 快捷档 + 自定义（小字体确保一行展示）

**Screen 2 口味分配：**
- 工具栏：已分配 X / Y 包 + 平均分配 / 重新分配
- 口味列表：每行显示口味名 + 单价（¥XX/包） + `[− X +]` 控件
- 一键均分：余数优先挂靠单价低的口味
- 价格面板：划线原价 + 折后总价 + 折扣率
- 热量偏差提示（仅回程路径，偏差 > 20% 时显示）

**Screen 3 方案结果：**
- 快照卡片（可见版 + 隐藏版供 html2canvas 渲染）
- 方案明细：宠物、配送日期、订阅总数（加粗）、口味分配
- 价格区：划线原价 + 折后总价（折扣标签淡红色底纹）
- 企微客服二维码（110px，细边框）
- 快照预览弹窗：统一提示「请截图保存后，长按图片添加客服并分享」

**按钮文案优化：**
- Screen 1 → Screen 2：「口味分配 →」
- Screen 2 → Screen 3：「方案结果 →」
- 复用 calories/ 箭头图片（`.btn-next::after`）

**calories/ V3.23 联动（条件隔离，正常入口零感知）：**
- `from=plan` URL 参数检测
- 跳过 Step 0 犬猫选择，犬锁定
- Step 1 上一步 → 「返回订阅计划」（CSS 箭头图标 + 文字，无重复 icon）
- Step 10 商城按钮条件替换为返回按钮
- 回程 URL：`plan/?from=plan&pet=dog&packs=平均每日包数&kcal=MER×0.85`
- plan/ 解析回程参数：预填每日包数、自动展开模拟计算、选中 30 天
